# Demo artwork

Catalogue cards use Steam header capsules (460×215). Those are too small for the product page, which shows a 16:9 image about 760px wide. Files in `heroes/` are the first Steam store screenshot for that app (usually 1920×1080). Grand Theft Auto VI uses the official landscape cover from the Rockstar artwork page. Marvel's Wolverine uses the PlayStation hero at 2400px wide.
